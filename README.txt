УСТАНОВКА НА GITHUB PAGES
1. В корень репозитория my-training-diary загрузите файлы index.html, sw.js, manifest.webmanifest, icon-180.png, icon-192.png, icon-512.png.
2. Убедитесь, что Pages: main / (root).
3. Откройте опубликованный сайт в Safari, затем Поделиться → На экран Домой → Добавить.
4. Один раз откройте установленное приложение при наличии интернета. После успешной установки кэша оно будет работать офлайн.
5. Для проверки включите авиарежим и откройте ярлык.
ВНИМАНИЕ: локальный HTML из Файлов не может установить Service Worker; он работает только с HTTPS/localhost. Данные сохраняются локально на устройстве и не синхронизируются. Сохраняйте резервные копии.
